7) Why is Java Platform Independent?

Java is platform independent because Java code is converted into bytecode, which can run on any
 operating system that has a JVM (Java Virtual Machine).

How it works:

Java Code (.java)
       ↓
   Java Compiler
       ↓
Bytecode (.class)
       ↓
      JVM
       ↓
Windows / Linux / Mac

    "Write Once, Run Anywhere (WORA)".
