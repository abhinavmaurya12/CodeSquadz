 ## 1\. Java Basics

 1. **Java:** High-level, class-based, object-oriented, statically typed language.
2. **JDK:** Tools required to develop Java applications.
3. **JRE:** Runtime environment for Java applications.
4. **JVM:** Executes Java bytecode.
5. **JDK = JRE + Development Tools.**
6. **JRE = JVM + Runtime Libraries.**
7. **JVM:** Platform dependent; **Java bytecode:** Platform independent.
8. **WORA:** Write Once, Run Anywhere.
9. **Source File:** `.java`
10. **Bytecode File:** `.class`
11. **Compiler:** `javac` converts source code → bytecode.
12. **JVM:** Bytecode → machine instructions.
13. **JIT:** Compiles frequently executed bytecode to native code at runtime.
14. **Main Method:** `public static void main(String[] args)`.
15. **Java is pass-by-value:** Even object references are passed by value.

 # 76\. Important Java Interview Differences

 677. **JDK vs JRE:** Development vs runtime.
